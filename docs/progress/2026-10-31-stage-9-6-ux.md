## Реализация

### 1. Per-profile сэмплирование (quick/deep/custom)

Было: профиль — только имя, все параметры сэмплирования общие (`scan.sample`).

Стало:
- `config.ScanConfig` получил `Quick`/`Deep` `SampleConfig`;
- `config.SampleForProfile()` — выбор параметров по профилю: quick/deep
  переопределяют default (sample), custom — сам default;
- `mergeSample()` — непустые поля override поверх base;
- `engineConfig` (cmd/zond) использует `config.SampleForProfile`;
- detectors.yaml: quick (1%, 5k rows, 100 chars), deep (10%, 50k rows, 500 chars);
- Валидация per-profile в `Detectors.Validate()`.

### 2. API rate-limit (п. 11.2)

`api.RateLimiter` — token-bucket по субъекту (actor: sso:subject, token:id,
admin-token, api). Default: 100 req/s (capacity=100, refill=100/s).
Подключён в `withAuth` после успешной аутентификации; 429 при превышении.

### 3. UX

- **Keyboard shortcuts y/n/l** для ревью (vanilla JS, без фреймворка):
  первая карточка в очереди, y=confirm, n=reject, l=relabel;
- **Скрытие admin-действий у viewer**: ссылки audit/settings/sources в nav,
  кнопки stop/resume/describe на /scans/{id} — только для admin.
