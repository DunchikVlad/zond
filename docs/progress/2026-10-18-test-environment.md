## 4. Примечания по безопасности

- Пароли стенда осознанно слабые — допустимо **только** для изолированного
  тестового контура; к продуктивным инсталляциям это неприменимо
  (blueprint п. 12, п. 14).
- Учётные записи БД на тестовых источниках — read-only, по blueprint п. 12;
  пароли/DSN источников в репозиторий не коммитить (`.gitignore` п. «Секреты»).
- SSH-доступ по паролю — временное допущение для тестового контура; для
  долгоживущего стенда рекомендуется перевод на ключи.
- На стенде запрещено размещать реальные ПДн и секреты — только синтетика
  (`cmd/seed`, blueprint п. 16.6, п. 24).

## 9. Дополнение 2026-11-01: новый стенд (Debian 13)

- **ОС**: Debian GNU/Linux 13 (trixie) на обоих хостах; CPU AMD Ryzen 7 7700

  Docker отсутствует, развёртывание нативное.
- **`.248` (приложение)**: `/opt/zond/{bin,configs,data,zond.env}`, systemd

  prod-заглушек конфига). sudo настроен (NOPASSWD для пользователя test).
- **`.64` (БД)**: ClickHouse 26.9.9.28 (deb-пакеты stable), listen
  0.0.0.0:9000/8123, пользователь `test`/`test` (профиль zond_readonly,
  readonly=2, п. 12), сид `default.customers` (8 строк). MongoDB 8.0.34

  закрыты Provides libssl3/libcurl4 t64-пакетов), authorization enabled,
  listen 0.0.0.0:27017, `test`/`test` (read на testdb) + `admin`/`test`,
  сид `testdb.customers` (8 документов).
- **Сеть стенда — ограничение**: исходящие загрузки больших файлов с
  внешних CDN (packages.clickhouse.com, repo.mongodb.org, deb.debian.org)
  идут на 10–15 КБ/с и apt-метод https зависает. Обход, применённый при
  развёртывании: скачивание deb-пакетов на машине разработчика → scp →
  `dpkg -i`. Учитывать при обновлении ПО стенда.
- **SSH**: `ssh test@<хост>`, пароль `test`, root тоже `test` (su),
  sudo NOPASSWD. Рекомендация п. 4 (перевод на ключи) в силе.
