## 3. Ключевые решения

- Module path — реальный: `github.com/DunchikVlad/zond` (бинарник `zond`);
  расхождение с blueprint (там артефакт `classifier`) зафиксировано в
  `docs/decisions/ADR-impl-zond-naming-and-scaffold.md`, переименование docs — отдельным чанком.
- Интерполяция `${ENV}` выполняется **после** YAML-парсинга (по строковым полям
  структуры) — иначе `${VAR}` в комментариях ломает загрузку; есть регрессионный тест.
- Отложено сознательно: `deploy/docker-compose.yml` (Docker отсутствует в среде —
  этап 1/2), Vault-конфиг (ADR-0012 — этап 7), hot-reload detectors.yaml (ADR-0014 — этап 4+).
