## 2. Что сделано

| Чанк | Результат |
|---|---|
| S6г-1 | `internal/benchlab` — детерминированный генератор (math/rand/v2 PCG, seed): позитивы всех 11 recognizer'ов `rules.Default()` с **валидными контрольными суммами** (ИНН-10/12 по весам ФНС, СНИЛС, Лун, IBAN mod-97) и форматные (email/phone/паспорт/счёт/IP/дата/UUID); негативы — 6 шаблонов, гарантированно не матчащихся ни одним recognizer'ом (инвариант — тест); микс по умолчанию 25/75 (консервативно: негатив — полный прогон regex) |
| S6г-1 | `benchlab.Run` — прогон `rules.Analyze` по «колонкам» (по умолчанию по 1000 значений) одной горутиной — зеркало пути scanengine (engine.go:431); замер только классификации (генерация до таймера); агрегат матчей по recognizer'ам; отчёт `zond/bench-report@1` (счётчики, duration, values_per_sec/min, NFR pass/fail, порог) |
| S6г-2 | `cmd/eval bench` — подкоманда контурa этапа 6 (не трогает store/секреты/SSO): флаги `-n/-seed/-col-size/-pos/-threshold/-out`; код выхода 1 при провале NFR (CI-гейт); `make bench`; шаг «Bench слоя 1 (NFR п. 18)» в ci.yml на каждый PR (`-out ""` — файл в раннере не нужен) |

Фактический прогон (эталонная машина разработки, go1.27.3 windows/amd64):
1 000 000 значений за 594 мс → ~1.68M знач/с (**~101M знач/мин на ядро**,
порог 100k — запас ~×1000, гейт устойчив к медленным CI-раннерам).
Кросс-матчи внутри позитивов (реалистичный профиль): ИНН-10 ↔ паспорт
(10 цифр), phone-формат «9xxxxxxxxx» ↔ паспорт, СНИЛС/ИНН с ведущей 7/8/9
↔ phone — матчи агрегируются по recognizer'ам, на замер не влияют.

## 3. Ключевые решения

См. `docs/decisions/ADR-impl-stage-6g-bench.md`. Кратко:

- **bench — подкоманда `cmd/eval`** (прецедент ADR-impl-6а D1), а не
  подкоманда `zond` и не отдельный бинарь: инструментарий этапа 6.
- **Собственный генератор, не evalset**: evalset — эталонный датасет F1
  (taxonomy, колонки, спуфы); bench — поток значений с контролируемым
  миксом и гарантией чексумм.
- **Формулы чексумм продублированы в benchlab** (не экспорт из rules):
  доменный API слоя 1 не размывается; корректность дублей — инвариантом
  теста «100% сгенерированных позитивов матчится своим recognizer'ом»
  (ловит рассинхрон формул, см. git-историю: Лун и 12-значный ИНН
  исправлены именно этим тестом).
- **Отчёт с wall-clock в git не коммитится** (`evals/reports/bench.json`
  в .gitignore): метрика недетерминирована; с ADR-impl-6б (детерминизм
  `report.json`) не конфликтует — разные артефакты.
