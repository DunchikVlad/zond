## D1. Что входит в hot-reload, что — нет

**Выбор:** hot-reload для scan.profile, ensemble (tau/веса), cluster,
proxy (лимиты/budget/offline). Реестр агентов и taxonomy.yaml — рестарт.

**Обоснование:** пороги/веса/лимиты — эксплуатационные ручки (запрос
«крутить настройки без рестарта»). Агенты трогают egress-политику,
endpoint и кэш-ключи LLM (cache scope = agent_id|model); taxonomy —
промпт-enum и словари слоя 0 (R6, промпт-дрейф). Эти изменения редки и
опасны — осознанный рестарт с перечитыванием файла уместнее (fail-closed).

## D2. Пороги применяются на старте прогона, а не мгновенно ко всем

**Выбор:** engineRunner получает bundle через atomic-провайдер при каждом
Start; действующие прогоны работают со снимком на своём старте.

**Отклонённая альтернатива:** мгновенная смена порогов «под ногами»
у работающих прогонов.

**Обоснование:** прогон должен быть сопоставим сам с собой (метрики,
аудит, дрейф-отчёты); смешение двух режимов внутри одного прогона делает
результат необъяснимым. Задержка ≤ длительности одного прогона — приемлема.

## D3. Общий bundle-провайдер вместо разрозненных holders

**Выбор:** connsHot заменён на bundleHot (atomic.Pointer[Bundle]);
applyConns/applyDetectors строят новый Bundle из текущего с заменой одной
части. web и runner читают через bundleCurrent()/bundle().

**Обоснование:** одна точка истины процесса; следующие reload-инкременты
(taxonomy под флагом осторожности) встанут без новой проводки. Bundle
копируется по значению (поля заменяются целиком) — читатели либо видят
старое, либо новое, без промежуточных состояний.

## D4. scalarAuto — типизация записываемых скаляров

**Выбор:** числа/бул пишутся без тега `!!str` (yaml типизирует при чтении),
строки — с тегом.

**Обоснование:** общий mappingSet из S8-7 всегда писал строки — для
detectors это сломало бы типы (cannot unmarshal !!str into float64).
Разделение по содержимому (ParseFloat/bool) решает без эвристик регулярок.
