# Security note: backup/restore (инкремент 7б, п. 15.2)

Дата: 2026-10-22
Изменение: `store.Backup`, `zond backup`/`zond restore`, расписание копий
(scheduler), правило `backup_failed`, секция `backup` в connections.yaml.

## Поверхность изменения

- Новые CLI: `zond backup -out <path>`, `zond restore -from -to`.
- Новая фоновая задача scheduler'а: копия БД по cron в каталог оператора.
- Новые аудит-записи: действие `backup` (категория admin) от cli и
  scheduler, включая неудачи.

## Меры (blueprint п. 14; fail-closed)

| Угроза | Мера |
|---|---|
| Перезапись/подмена существующей копии | VACUUM INTO только в несуществующий файл (проверка до копии); restore отказывается от непустого каталога назначения |
| Чтение копии посторонними | Права 0600 на созданной копии (только владелец); каталог — вне инстанса по политике оператора (S3/WORM, п. 14.2) |
| Утечка данных через копию | Копия = снимок Verdict Store: значения уже маскированы по построению (ADR-0010); секретов в store нет (DSN/ключи живут в ENV); шифрование — на уровне ФС/диска (п. 15.2) |
| Действие без аудита | Каждая попытка (ok/fail) — аудит-запись в hash-chain (п. 14.2); CLI backup: запись после успеха, при неудаче — запись с ошибкой; scheduler: в обоих случаях |
| Подделка факта копии | Аудит append-only с hash-chain: запись backup не переписывается; правило алертинга читает тот же журнал |
| Угадывание путей через restore | Пути задаёт оператор CLI; чтение только `--from`, запись только в `--to/zond.db` при отсутствии файла |
| Эксфильтрация через расписание | Каталог копий — из конфигурации оператора (не пользовательского ввода); секция `backup` без секретов, строгая схема YAML |

## Принятые риски / ограничения

- **Копия не шифруется сама** — п. 15.2 относит шифрование на уровень
  ФС/диска; для S3 — SSE/S3-WORM-политика оператора.
- **RPO-контроль опирается на аудит инстанса**: если копия делается
  внешним cron'ом (вне zond), правило её не видит — либо расписание
  zond, либо внешний мониторинг.
- **Задержка обнаружения неудачи** — до 5 минут (расписание алертов),
  плюс расписание самой копии.
