# Security note: генератор eval-датасета (инкремент 6а, п. 16.6)

Дата: 2026-10-21
Изменение: пакет `internal/evalset`, бинарь `cmd/eval`, артефакты в `evals/dataset/`.

## Поверхность изменения

- Новый CLI: `cmd/eval generate` — читает `configs/taxonomy.yaml`, пишет
  `manifest.json` + `columns.jsonl` в `-out` (default `evals/dataset`).
- Новый код в дереве: `internal/evalset` (генератор, словари, чексуммы).
- Закоммиченные артефакты: 1000 колонок синтетических значений, включая
  Luhn-валидные PAN-подобные номера и чексумма-валидные ИНН/СНИЛС.

## Меры (blueprint п. 14)

| Угроза | Мера |
|---|---|
| Реальные PII в репозитории через датасет | Генератор синтетический (Faker-аналог, п. 16.6): словари — общеупотребительные имена/фамилии/города/улицы, не привязанные к реальным лицам; числа — случайные с корректными чексуммами (Luhn/ИНН/СНИЛС/IBAN — публичные алгоритмы, валидность ≠ существование счёта/карты) |
| Чексумма-валидные PAN в free_text могут быть приняты за реальные карты | Это номера из случайных 15 цифр + check digit: BIN случайный, эмитент/счёт не существуют; комментарием зафиксировано в progress-доке |
| Утечка секретов генератором | Генератор не читает ENV, не ходит в сеть, не трогает секреты; вход — только taxonomy.yaml (без секретов) |
| Подмена эталона (датасет в git) | Детерминизм: seed в манифесте, повторная генерация даёт побайтовый результат (проверено cmp) — любая правка колонок видна в diff |
| Исполнение чужого кода через -out | `evalset.Write` пишет только два фиксированных имени в заданный каталог (MkdirAll 0755, файлы 0644), путей из данных нет |
| Логирование | CLI печатает только сводку манифеста; значения не логируются |

## Принятые риски / ограничения

- **Luhn-валидные PAN и чексумма-валидные ИНН/СНИЛС в git** — неизбежность
  п. 16.6 («валидные негативы внутри свободного текста», спуфы должны быть
  форматно неотличимы). Риск: внешние сканеры секретов могут флаговать
  репозиторий; номера не принадлежат эмитентам и не идентифицируют лиц.
  Mitigation при необходимости — пометка `evals/dataset/` в
  `.gitattributes`/доке как synthetic.
- Словари имён маленькие (48/48/30) — комбинации повторяются между колонками;
  для оценки классификатора достаточно, для «тренировочного» датасета — нет
  (не цель проекта).
