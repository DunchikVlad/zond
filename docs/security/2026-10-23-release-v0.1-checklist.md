## 3. Открытые пробелы v0.1 (явно)

1. **Circuit breaker per source (п. 13.2)** — не реализован. Компенсация
   сейчас: 1 прогон на источник, таймауты, fail-статусы таблиц. Завести
   отдельным инкрементом.
2. **SIEM-sink аудита (п. 14.2, опция)** — не реализован; retention и
   verify локальными средствами закрывают базовый сценарий.
3. **Шифрование тома БД** — требование инсталляции (п. 14), проверяет
   оператор при вводе; автопроверка в doctor не делалась (cross-platform
   ненадёжность).
4. **Scratch-образ non-root (п. 15)** — Dockerfile/compose контур
   приходят со smoke S7г-6.
5. **LICENSE-файла в репозитории нет** — go-licenses игнорирует собственный
   модуль; выбор лицензии — продуктовое решение, требует владельца.
6. **Эталонный контур (smoke ≤15 мин, F1-метрики п. 22)** — compose +
   seed + прогон метрик — S7г-6/next; LLM-метрики ($/1000, F1 семантики)
   ждут LLM-стенд.

## 4. Решение

Меры п. 14, критичные для релиза (утечки, доступ, аудит, brute-force,
CSRF/XSS/SSRF, уязвимости зависимостей), реализованы и подтверждены
тестами/CI. Перечень раздела 3 — не блокеры выпуска артефактов, но
блокеры объявления «эталонный контур DoD полностью зелёный»: до них тег
v0.1 не ставится (см. HANDOFF, следующие шаги).
