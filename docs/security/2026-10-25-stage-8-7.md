# Security note: S8-7 — управление источниками и расписаниями из UI

Дата: 2026-10-25
Изменение: страница /sources (admin-only) правит connections.yaml
(источники, schedule, scan_window) с горячим применением.

## Поверхность изменения

- Новые маршруты: GET /sources, POST /sources/save,
  POST /sources/{name}/delete, POST /sources/test — все за RBAC-действием
  `manage` (только admin, п. 11.3). Действие добавлено в матрицу rbac.
- Запись в конфигурационный файл процесса; перечитывание конфигурации;
  перестройка cron-расписаний.
- Аудит-записи admin/source_add|update|delete.

## Меры (blueprint п. 14; fail-closed)

| Угроза | Мера |
|---|---|
| Подмена запроса на правку (CSRF) | Классические формы с csrf_token-полем (S8-6); мутации POST-only; SameSite=Lax |
| Правка неавторизованным пользователем | RBAC ActionManage = admin-only (п. 11.3); dev-режим (SSO выключен) — субъект dev=admin, применимо только к тестовому контуру |
| Утечка секретов через UI/аудит/логи | dsn/uri в формах — raw с `${ENV}` (как в файле); аудит НЕ содержит строк подключения (только name/type/schedule/window); сериализация через yaml.Node round-trip — в памяти раскрытых значений нет, записываются только исходные литералы |
| Открытый пароль в файле через UI | **Отказ при сохранении**: пароль в userinfo должен быть `${ENV}` (п. 12); fail-closed, тесты обеих СУБД |
| Порча файла (битый YAML/схема) | Валидация записи до записи + ValidateAll по строгой схеме; атомарная замена через tmp+rename; резервная копия `.bak` перед записью; при неудаче применения (например, новый ENV не задан) — файл записан, но процесс не переключается, явное сообщение |
| Подмена типа/расписания для вреда | type — enum clickhouse|mongodb; schedule — cron.ParseStandard; scan_window — ParseWindow (в т.ч. отказ от вырожденного окна) |
| SSRF через «Проверить» | Коннектор строится через реестр (factory по типу), egress-политика не применяется к источникам by design (источники — доверенная конфигурация admin); пинг с 10-секундным дедлайном |
| Гонки при горячем применении | atomic.Pointer для connections; scheduler под мьютексом (rescanEntries/windows); race-тесты |

## Принятые риски / ограничения

- **Правки файла теряют inline-комментарий изменяемой строки** (Node
  заменяет значение) — секционные комментарии сохраняются; зафиксировано
  тестом.
- **Удаление источника во время его прогона** не блокируется: активный
  прогон завершится, расписание снято — приемлемо для оператора.
- **`.bak` содержит прежний файл** (с ${ENV}-литералами, без секретов)
  рядом с конфигом — доступ по правам каталога конфигурации.
- Новая переменная окружения для подключения требует рестарта serve
  (env процесса) — UI об этом сообщает; hot-reload ENV не входил в скоуп.
