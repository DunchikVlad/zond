# Security note: preflight doctor (инкремент 7а, п. 15.3)

Дата: 2026-10-22
Изменение: пакет `internal/doctor`, подкоманда `zond doctor`, флаг
`serve -strict`, `golang.org/x/sys` — прямая зависимость.

## Поверхность изменения

- Новый CLI: `zond doctor` (offline по умолчанию; `-online` — Ping
  источников, DNS и пробные вызовы агентов).
- `serve -strict` — блокировка старта по FAIL preflight.
- Исходящие сетевые обращения в online-режиме: Ping коннекторов,
  DNS-резолв, пробный вызов LLM-прокси (только явный `-online` или
  `-strict`).

## Меры (blueprint п. 14; fail-closed)

| Угроза | Мера |
|---|---|
| Утечка секретов в отчёт | Детали проверок — только метаданные (пути, env-имена, ошибки); ключи, DSN, значения не выводятся; agent.probe шлёт в LLM фиктивные значения (маскирование прокси п. 10.2 действует и здесь) |
| SSRF/нежелательные вызовы в online-режиме | Пробные вызовы идут через agentproxy (единственная точка LLM, п. 10.1) с его egress-политикой; Ping — только по источникам из конфигурации оператора; таймауты (10с ping, timeout_s агента) |
| Фейковый/опечаточный endpoint агента проходит offline-проверку | Egress-валидация (включая DNS-резолв, fail-closed п. 10.7) выполняется и без `-online` — прецедент agent-check; endpoint, который не резолвится/запрещён политикой, даёт FAIL сразу |
| Блокировка serve из-за doctor | `-strict` — опт-in флаг; без него serve стартует как раньше; отчёт strict идёт в stderr (не в лог с секретами) |
| Чтение чужого пути через -db | Путь задаёт оператор CLI (как у scan/serve); отчёт не читает файлы вне dbPath/путей конфигурации |
| Подмена проверяемого сертификата | tls.cert читает путь из конфигурации инстанса, сверяет срок на «сейчас» проверяющего; парсинг x509 безопасен к malformed-вводу (ошибка → FAIL, не паника) |

## Принятые риски / ограничения

- **DNS-проверка подвержена DNS rebinding-подобным гонкам** TOCTOU (резолв
  на момент doctor ≠ момент вызова) — природа preflight, не устраняется.
- **IdP metadata / revocation-списки не проверяются** (п. 15.3 перечисляет
  TLS/DNS/env) — refresh метаданных IdP есть в serve (S5в-5); CRL — вне
  скоупа v0.1.
- **Windows-реализация freeSpace через GetDiskFreeSpaceExW** — точность до
  байта на уровне WINAPI; POSIX — Statfs (Bavail×Bsize), обе вариации
  округляют вниз при нехватке — безопасно для проверки «≥2×».
