## 3. Подтверждено поведение по blueprint

- **п. 8 флаттенинг**: `address.city`, `tags[]` (K=5), `items[].field`, глубина
  ≤5 → `...` — unit-тестами.
- **п. 8 полиморфизм**: схема = объединение ключей; ≥2 типов в >20% документов →
  `native_type "mixed"` + список типов; редкий тип (≤20%) не делает путь mixed —
  unit-тестами.
- **п. 8 `_id`**: исключается из классификации (`skipPath`) — тестом.
- **п. 8 типизация**: BSON-класс значения (string/number/bool/null/object/array) —
  табличным тестом.
- **п. 16.2 conftest**: общий `RunConformance` (ListTables/GetSchema/CountRows/
  Sample, MaxRows, NULL→nil) против обеих БД через testcontainers — код готов,
  прогон в CI.
- **п. 5.1 Sample**: соблюдение MaxRows — проверкой в conftest.
- **п. 4 конвенция путей**: коннектор подключён blank-import'ом, ядро не
  изменялось (только `cmd/zond/main.go`).

## 4. Что не проверено (с причинами)

- **Реальные CH/Mongo в контейнерах** — Docker отсутствует локально; conftest
  прогонится в CI (ubuntu-latest + Docker). До зелёного CI контрактное
  соответствие подтверждено только кодом и unit-тестами, не живым прогоном.
- **Стратификация $sample (стат-тест равномерности, п. 16.2)** — отложена
  (ограничение шардированного $sample зафиксировано в п. 8); вместе с
  CH-стратификацией — этап 3/6.
- **`zond scan -source mongo-test`** против живого стенда — БД на
  192.168.31.119 не установлены (см. test-environment).
- **golangci-lint** — локально не установлен; результат — в CI.

## 5. Остаточные риски

- **mongo-driver v2.9.2 — новая зависимость**: первый прогон интеграционного
  теста может выявить расхождения API (v2 vs v1) на реальном Mongo; mitigация —
  CI-прогон, при необходимости пин версии.
- **$sample на маленьких коллекциях** может вернуть меньше запрошенного size —
  допустимо для MVP (фиксируется в п. 8), conftest проверяет верхнюю границу
  (MaxRows), не нижнюю.
- **mixed-тип сейчас не эскалирует в LLM** (LLM-слой — этап 4): путь с
  `native_type "mixed"` помечается, но принудительная отправка в ревью — после
  появления Agent Proxy.
