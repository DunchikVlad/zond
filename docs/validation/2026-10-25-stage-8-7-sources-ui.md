## 2. Что подтверждено тестами

- **SourceEditor**: список без интерполяции (raw `${ENV}`); upsert
  (добавление + обновление) и delete; сериализация сохраняет секционные
  комментарии и литералы `${ENV}`; ValidateAll строго по схеме;
  отказы валидации: пустое/чужое имя, неизвестный тип, отсутствующий
  dsn/uri, **пароль открытым текстом (clickhouse и mongo)**, невалидный
  cron, окно `25:00-…` и вырожденное `03:00-03:00`; пример окна через
  полночь принят.
- **scheduler.ReplaceSources**: пересборка cron без рестарта (число
  entries не меняется при замене источников, окна обновляются/снимаются,
  rescanEntries синхронны).
- **web /sources**: viewer → 403 на сохранение; admin → 303, applyConns
  вызван, файл содержит новое расписание/окно, обновление существующего
  не плодит записи; источник с открытым паролем не записан; аудит
  содержит source_add и source_update.
