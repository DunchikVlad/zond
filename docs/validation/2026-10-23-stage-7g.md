- **`make smoke` (compose-подъём и quick-скан)**: docker в окружении
  сессии отсутствует. Контур собран по спецификации (healthcheck-гейтинг,
  общий том БД), но не исполнялся. Прогон — обязательный следующий шаг
  перед тегом v0.1 (ADR-impl-stage-7g D7).
- **`release.yml`**: написан по спецификации GitHub Actions; сработает на
  push тега (матрица, syft, cosign OIDC, gh-release). Локально не
  исполняем по построению.
- **Эталонные LLM-метрики DoD** (F1 структурных ≥0.97 / семантики ≥0.75,
  $/1000, доля без LLM ≥70%): требуют LLM-стенд (отсутствует) и прогон
  smoke-контура. Без-LLM часть (`make eval`, датасет) — работала в S6а/S6б.
- **Dockerfile**: статически корректен (scratch + один бинарь + CA);
  сборка образа не выполнялась (нет docker).
