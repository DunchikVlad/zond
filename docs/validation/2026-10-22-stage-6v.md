## 2. Что подтверждено тестами

- **Meter** (meter_test.go): снимок счётчиков (сканы по статусам, llm,
  кэш, кластеры, токены, cost×1e6, вердикты); String() — валидный JSON;
  PublishExpvar идемпотентна, /debug/vars содержит zond/process.
- **Инструментация движка** (scanengine/observe_test.go): E2E-прогон с
  fake-LLM (2 ok-вызова: classify+verify) — дельты Default точны
  (scans started/finished=1, by_status[done]=1, llm_calls=2, токены
  150/30, verdicts=6, кэш/ошибок 0).
- **Store-агрегаты** (store/observability_test.go): окно 24ч считает
  calls(ok+error)/errors/cache, токены и $ только по ok (конвенция
  движка; cache_hit в сумму не входит), latency-выборка отсортирована;
  серия ошибок (6 подряд → 6, агент последней ошибки; ok обнуляет);
  LatestScanOverviews — последний прогон на источник (pending, llm-
  колонки без кэша, no_llm_share; вердикты старых прогонов не мешают);
  ReviewActionCounts за окно.
- **Snapshot** (observe/snapshot_test.go): перцентили ближайшим рангом
  (p50=50, p95=100 на выборке 10..100; пустая → 0), cache_hit_share,
  unavailable при streak>5, сводка по источникам, доля confirmed;
  пустой store — снимок без паник, window=default.
- **Эндпоинт** (api server_test.go): GET /api/v1/stats/metrics — 200,
  обязательные секции process/llm/sources/review/generated_at/window.
- **Алерты store** (store/alerts_test.go): дедуп открытых по (rule,target)
  с продлением last_seen/details, другая цель — новый алерт; закрытие
  не-активных (AlertResolveNotIn) с resolved_at; фильтры списка open/
  resolved; счётчик открытых.
- **Evaluator** (observe/alerts_test.go): смешанный сид (budget_exceeded +
  pending 7 при пороге 5 + 6 ошибок LLM) → ровно 3 алерта с ожидаемыми
  целями (source:ch, source:mongo, agent:zond-main), целая цепочка аудита
  не стреляет; 3 аудит-события alert_raise от scheduler; повторный прогон
  не дублирует; исчезновение условия закрывает алерт с alert_resolve
  (raise/resolve = 1/1); webhook (httptest) получает raised+resolved с
  полями rule/severity/target.
- **Scheduler** (scheduler_test.go): задача алертов по @every 1s вызывает
  fn (атомик-счётчик, канал-гейт; race-детектор чист).
