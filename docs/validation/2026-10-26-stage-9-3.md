## 2. Сценарии приёмки

### Prompt-контракт и изоляция

- `NormalizeUser`: пустое/пробельное → ""; trim; ровно 2000 символов проходит,
  2001 — отказ; NUL — отказ.
- `UserHash`: детерминирован, различает инструкции, пустая инструкция → пустой
  хэш (ключ кэша прежней длины).
- `SystemWithInstruction`: базовый промпт сохранён целиком, инструкция в
  `<operator_instruction>`, фиксация неотменяемости правил и enum на месте;
  аналогично верификатор.
- Proxy (fake-LLM записывает тело): инструкция в system классификатора и
  верификатора; без опции блок отсутствует; сырых значений нет (маск-профиль
  не изменился; префикс/суффикс маски видны по дизайну).

### Разделение кэша и provenance (движок)

- Два прогона с одинаковыми значениями/scope: тот же промпт → cache_hit;
  другой промпт → повторный сетевой вызов (ключ кэша различен).
- `GetScan` возвращает prompt_base_version/prompt_hash/prompt_text/llm_enabled;
  без LLM и промпта — честные пустые значения.
- Аудит scan_start содержит prompt_hash, prompt_len (в рунах) и llm-флаг,
  полного текста нет.
- `ValidateResume`: несовпадение prompt_base_version и prompt_hash — отдельные
  mismatch'и; legacy-пустые значения несовместимы fail-closed.

### Store и миграция 0012

- Round-trip новых полей через SaveScan → GetScan/ListScans/
  LastCheckpointScan.
- up/down/up без ошибок; upgrade с 0011: legacy-строка получает пустые
  provenance-поля (не угадывается); после down/up строки читаются, значения
  сброшены в DEFAULT (DROP COLUMN необратимо — зафиксировано в тесте).

### API / UI / CLI / scheduler

- REST: user_prompt нормализуется и доходит до runner; `llm:true/false` —
  как *bool, без поля — nil (default сервера); сверхлимит, NUL (через
  JSON-escape) и неизвестные поля → 400 `invalid_request`, runner не вызван.
- Web: форма /scans содержит textarea и select LLM; POST передаёт нормализованный
  промпт и флаг; сверхлимитный ввод — 400 без вызова runner.
- Scheduler: пересканы идут с пустым UserPrompt и без LLM-override (фиксация в
  fakeStarter).
- CLI: `-prompt` нормализуется; `-prompt` с `-resume` отклоняется; resume
  воспроизводит сохранённые промпт и llm-флаг (TestRunnerResumeProvenance
  зелёный с новыми полями provenance).
