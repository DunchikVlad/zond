## 2. Что подтверждено тестами (`internal/evalset/evalset_test.go`)

- **Детерминизм**: два `Generate` с одним seed → `bytes.Equal` JSON всех
  колонок (TestGenerateDeterministic); порядок колонок стабилен
  (TestColumnOrderStable).
- **Квоты и покрытие**: все 18 лейблов таксономии представлены, суммы
  `Counts` сходятся с Total, позитивы распределены максимально равно
  (TestPositiveCountsAndCoverage); при маленьких Total квоты не съедают
  позитивы, минимум 1 позитив на лейбл (TestSmallTotal).
- **Связка с regex-слоем** (ключевой self-check датасета):
  - TestPositivesDetectableByRules — для каждой positive-колонки с
    recognizer'ом (PHONE, EMAIL, TAX_ID, SNILS, PASSPORT_ID, CARD_NUMBER,
    BANK_ACCOUNT, IP_ADDRESS, DATE_TIME, IDENTIFIER; DATE_OF_BIRTH — через
    date-recognizer) доля детекта `rules.Default()` ≥ 0.9;
  - TestSpoofsRejectedByRules — каждое значение каждой spoof-колонки
    (TAX_ID/SNILS/CARD_NUMBER/IBAN) НЕ матчится соответствующим
    recognizer'ом: спуфы действительно «похожи, но неверны».
- **Целостность формата**: значения однострочные (нет `\n`/`\r`), не пустые,
  ID уникальны (TestValuesSingleLineAndNonEmpty); Write→чтение round-trip
  (TestWriteRoundTrip).
- **Прочее**: минимальные размеры словарей (TestDictionaryMinSizes),
  генерация 1000×20 < 5 с (TestGeneratePerf), валидация Config
  (TestGenerateErrors).

## 3. Ручной осмотр выдачи

- Позитивы PHONE/EMAIL/ИНН/СНИЛС/PAN/IBAN/UUID/даты соответствуют форматам
  recognizer'ов; ИНН и СНИЛС — с настоящими контрольными суммами.
- Спуфы визуально неотличимы от валидных (те же длины/структуры), чексуммы
  битые — цель ложняка достигается.
- free_text: валидный PII (реальный Luhn/чексуммы) вшит в прозу — ловушка
  для слоя 1; ~3/4 значений колонки — чистый текст (реализм).
- mixed/polymorphic: значения-строки чисел/булов/null/json-фрагментов и
  JSON-массивов с разнотипными элементами — однострочные, валидный JSON.

## 4. Ограничения

- Self-check завязан на ТЕКУЩИЙ regex-слой: регрессия recognizer'ов,
  наоборот, ловится тестами evalset (связка двусторонняя); расхождение —
  сигнал чинить слой или генератор осознанно.
- Лейблы без recognizer'а (PERSON_NAME, ADDRESS, GEO_LOCATION и служебные)
  проверяются только структурно — их качество оценит S6б (F1).
